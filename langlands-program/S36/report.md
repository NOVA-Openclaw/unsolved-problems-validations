## DERIVED: missing admissibility argument (Lemma 2.1)
Unramified E: Gal(EK/E) is generated by x ↦ x^{q^ℓ}; since gcd(ℓ,f)=1, q^ℓ generates the same subgroup of (ℤ/M)^× acting as ⟨q⟩ of order f, and N: k_{EK}^× → k_K^× is surjective, so admissibility transfers.
Totally ramified E (needs ℓ \| q−1): θ̃ on residue units is θ^ℓ (exponent a ↦ ℓa mod M, M = q^f−1). A failure needs x = a(q^j−1) ≢ 0 with ℓx ≡ 0 mod M, i.e. M/ℓ ∈ (q^g−1)ℤ for g = gcd(j,f) < f. But (q^f−1)/(q^g−1) ≡ f/g mod (q−1), hence ≢ 0 mod ℓ because ℓ ∤ f; so v_ℓ(M) = v_ℓ(q^g−1). Now a(q^j−1) lies in (q^g−1)ℤ/M and in (M/ℓ)ℤ/M, whose intersection is lcm(q^g−1, M/ℓ)ℤ/M = Mℤ/M = 0 (q^g−1 carries the full ℓ-part of M, M/ℓ carries everything else). So a(q^j−1) ≡ 0, contradicting admissibility of θ ⇒ θ̃ admissible. The hypothesis ℓ ∤ d (hence ℓ ∤ f) is exactly what is used; the paper does not say so.

## DISCREPANCY (minor, statement-level): Lemma 3.2 at ℓ = 2
Paper: two extensions satisfy T'_σ = c·T_σ with c^ℓ = 1, "which implies that c = 1 as 𝒦 is the maximal unramified extension of ℚ_ℓ". True for ℓ odd (ℚ_ℓ(ζ_ℓ)/ℚ_ℓ is totally ramified of degree ℓ−1 > 1). **False for ℓ = 2:** c = −1 ∈ ℚ_2. The case ℓ = 2 is inside the paper's hypotheses (p odd, d odd, E/F quadratic).
Consequence (C5, exact): under the sign-twisted extension σ ↦ −T_σ, on the rank-1 local model Ĥ⁰ and Ĥ¹ **swap** (Ĥ⁰ = 0, Ĥ¹ = O/2). Propagated through the Treumann–Venkatesh induction isomorphism (Prop 3.1), this gives Ĥ⁰(σ, L_Π) = 0 and Ĥ¹(σ, L_Π) ≅ r_2(π)^{(2)}.
Impact: Thm 1.1 remains correct for the **natural** action (σ·f)(g) = f(σ⁻¹g) that the proof actually uses; but "Ĥ^i(Gal(E/F), L_Π)" is not well-defined at ℓ = 2 without specifying it, and Corollary 3.5's "for any O_𝒦[D_E^×⋊Gal]-stable lattice L" is false at ℓ = 2 if the Gal action is allowed to be the sign twist. Fix: state the natural action explicitly (or restrict the uniqueness claim to ℓ odd). Also a typo: "c^ℓ = 1 … implies that c = 1" reads "Tσ^ℓ = Tσ'^ℓ = id, we get that c = 1, which implies that c = 1".
This is well known to specialists (Tate cohomology parity with sign twists at ℓ = 2 is exactly why TV fix the action); DERIVED, not independently confirmed by a second reader.
