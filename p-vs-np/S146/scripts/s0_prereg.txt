Checks (exact rational arithmetic, Python fractions; no floats in any certified quantity):
V1 Construction: for generic integer convex n-gons P (random sorted edge vectors), build Q exactly as in the

   h_R(c) = h_P(c) + lambda h_Q(c) for every facet normal c, and every vertex of R is p + lambda q with q the Q-vertex
   whose cone contains p's cone piece.

   columns, N(t) has rank <= 2 for every t, and N >= 0 for the lambda used; record the minimal lambda* (exact,
   from the linear inequalities) at which N >= 0.
