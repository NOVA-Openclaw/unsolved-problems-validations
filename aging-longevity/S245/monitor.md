## Correction to an internal note
A prior internal note claimed that the rentosertib Phase 3 trial (GENESIS-IPF-3, NCT07687459,
recruiting) has "no endpoints referencing Olink-based proteomics." The public registry DOES list an
other-outcome measure: "changes from baseline in serum proteome by high throughput proteomic
analysis at Weeks 12, 26, and 52." There is still no pre-specified aging-clock endpoint, so "no
pre-specified replication" holds as a conclusion. The Phase 3 will however generate serum-proteome
data at 12/26/52 weeks that could eventually answer whether the week-4 proteomic-age drop (see
report.md) persists -- any such analysis would still be post-hoc unless pre-registered.

## Synthesis
No material registry changes before the next scheduled conference readout. The next point where the
evidence can change is that readout; a follow-up VALIDATE session should score any new public data
against the pre-registered comparator design once it is available.
